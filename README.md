# Data Structures in C

Implementation of the main data structures studied in the Algorithmics and Data Structures course.

## Files

- `arrays.c` - Arrays, insertion, deletion and direct access
- `singly_linked_list.c` - Singly linked list
- `doubly_linked_list.c` - Doubly linked list
- `circular_linked_list.c` - Circular linked list
- `stack.c` - Stack (LIFO)
- `queue.c` - Queue (FIFO)
- `hash_table.c` - Hash table with chaining
- `structures.c` - Structures in C

## Compilation

Example:

```bash
gcc arrays.c -o arrays
./arrays
```

For another file:

```bash
gcc singly_linked_list.c -o singly_linked_list
./singly_linked_list
```

No `.h` files are used in this project.
